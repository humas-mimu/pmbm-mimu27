FOTO KEGIATAN & PRESTASI SISWA (tampil di Beranda)
==================================================
Cara menambah foto: cukup taruh file gambar di folder ini (public/galery).

* JUDUL FOTO = NAMA FILE (tanpa .jpg). Contoh:
    Juara 1 Lomba Tahfidz Tingkat Kecamatan.jpg  ->  tampil dengan judul "Juara 1 Lomba Tahfidz Tingkat Kecamatan"
* URUTAN: awali nama file dengan angka. Contoh: 01-..., 02-..., 03-...
  (angka di depan hanya untuk urutan, tidak ikut tampil sebagai judul). Tanpa angka = urut abjad.
* UKURAN: semua foto ditampilkan dengan TINGGI SAMA; lebarnya mengikuti rasio foto.
  Saran: tinggi sekitar 800 px, ukuran file di bawah 300 KB (kompres dulu lewat squoosh.app atau tinypng.com),
  format JPG / PNG / WEBP.
* HAPUS foto "Contoh - ..." bawaan sebelum website dipakai sungguhan.

Setelah menambah/menghapus foto:
  - Lokal  : hentikan lalu jalankan lagi "npm run dev" (daftar foto dibuat ulang otomatis).
  - Online : upload (push) ke GitHub, Vercel akan membuat daftar foto otomatis saat deploy.
Bila folder ini kosong, area galeri di Beranda otomatis disembunyikan.
