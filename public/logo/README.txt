LOGO MADRASAH (cara kedua, tanpa upload)
========================================
Ganti file madrasah.svg di folder ini dengan logo madrasah Anda (nama file tetap: madrasah.svg).
Boleh juga memakai PNG dengan nama: madrasah.png (hapus/rename madrasah.svg agar PNG yang terpakai).

Urutan pemakaian logo:
  1. Logo yang di-upload lewat menu Settings (jika ada)
  2. public/logo/madrasah.svg
  3. public/logo/madrasah.png
  4. Huruf pertama nama madrasah (jika semuanya tidak ada)

Untuk memakai file di folder ini: di menu Settings tekan "Hapus" pada logo, lalu "Simpan Pengaturan".
Setelah mengganti file, jalankan ulang/deploy ulang, lalu muat ulang browser (Ctrl+Shift+R).

FAVICON (ikon di tab browser)
=============================
Sama seperti logo, ada dua cara:
  1. Upload lewat menu Settings (kolom "Favicon"), atau
  2. Ganti file di folder public: favicon.svg (dan favicon.ico / apple-touch-icon.png bila perlu).
Favicon hasil upload dipakai lebih dulu; tombol "Hapus" mengembalikan ke file di folder public.
Browser menyimpan favicon cukup lama: tutup lalu buka lagi tab-nya, atau muat ulang dengan Ctrl+Shift+R.
